# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built with **React** and **Vite** to showcase my projects, technical skills, and journey as a Computer Science student.

## 🚀 Live Demo

🔗 https://spidey-portfolio.netlify.app/

- 🎨 Modern and responsive design
- ⚡ Fast performance with Vite
- 👨‍💻 About Me section
- 💼 Project showcase
- 🛠️ Skills section
- 📞 Contact section
- 🌙 Smooth UI and animations

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/papneetswain4-alt/portfolio.git
```

Go to the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
